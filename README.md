Sakura Ghost Game 🌸👻

About the Game

Sakura Ghost Game is a simple and fun clicking game where players try to catch a cute anime-style ghost before time runs out. The game has a Japanese-inspired theme with cherry blossoms, stars, and a glowing moon.

How I Built It

I created the game using JavaScript and the p5.js library. I used shapes, colors, and drawing functions to design the ghost, background, moon, stars, and cherry blossoms. I also added mouse-click interactions, a scoring system, random ghost positions, and a 30-second timer.

How to Play

1. Click the screen to start the game.
2. A cute ghost will appear in a random position.
3. Click on the ghost to catch it and earn 1 point.
4. The ghost will move to a new random position after each successful click.
5. Try to catch as many ghosts as possible before the 30-second timer runs out\!
6. When the game ends, your final score will be displayed. Click again to play another round.

Have fun catching ghosts!🌸
